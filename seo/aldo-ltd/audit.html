Findings, worst first

  1. P0Search engines don't know the site

    A web search for "aldo.ltd" Aldo Hushi returns only the ALDO footwear brand. A search for "Claude Code cost audit Glassbox flight recorder" lists ccusage-style competitors, Claude Flight Recorder and blackbox, but not Glassbox or aldo.ltd.

    Verify the domain in Google Search Console and Bing Webmaster Tools (DNS TXT record), submit /sitemap.xml, and use URL Inspection → Request indexing on /, /audit/, /claude-code-cost-patterns/, /redact-claude-code-session/, /sample-agent-cost-audit/ and the six-rungs pillar. Bing matters twice: ChatGPT search and Copilot draw on its index. Turn on IndexNow in Bing Webmaster so every publish pings it.

  2. P0Aldo's own properties barely link to it

    The Glassbox and Bearings package.json homepages point at GitHub. The GitHub profile README linked BlueprintAU but not aldo.ltd. These are the links Aldo controls and the first ones a crawler follows to a new domain.

    Done in this repo: the profile README now links aldo.ltd and aldo.ltd/audit/. Still to do: add a "Want a person to read it? → aldo.ltd/audit" line near the top of the Glassbox README; put aldo.ltd in the LinkedIn, X, GitHub and npm profile website fields; link aldo.ltd from the BlueprintAU footer and from aldo.today.

  3. P0No crawlable favicon

    /favicon.ico, /apple-touch-icon.png and /site.webmanifest all 404. The icon is a data: URI in the head, which Google doesn't use for search results, so aldo.ltd shows a blank globe next to its listing.

    Upload the six files in seo/aldo-ltd/drop-in/ to the web root and swap the head lines for head-snippet.html. They are the same sun-over-water mark, rendered to ICO, SVG and PNG.

  4. P1Meta descriptions cut off on the two pages that sell

    Home is 219 characters and /audit/ is 294. Google cuts around 155, so the audit snippet loses its price and its promise.

    Paste the rewrites from meta-descriptions.md (147 and 153 characters).

  5. P1"Glassbox" is already a company name

    Glassbox is also an established session-replay analytics company. Without a qualifier, Google and the AI engines will attach mentions of Glassbox to that company instead of to Aldo.

    Always write the qualified name in titles, H1s, alt text and the first sentence: "Glassbox for Claude Code" or "glassbox-trace". Make the SoftwareApplication name "Glassbox for Claude Code" and add "alternateName": "glassbox-trace".

  6. P1The Person entity changes from page to page

    There are three different jobTitle values (home, /audit/, the guides), and the sameAs lists differ: blog posts have 4 links and no Facebook, home has 5. Knowledge-graph systems trust an entity that describes itself the same way everywhere.

    Paste person.jsonld into the @graph of every page. It adds worksFor BlueprintAU, knowsAbout and the npm profile (fill in the username).

  7. P1One domain, three audiences

    aldo.ltd talks to Claude Code teams (audit, guides), recruiters (agent) and Adelaide small businesses (the ten six-rung SEO posts). The SEO cluster has no link from the homepage, and its calls to action send readers to blueprintau.com/check/. Mixed topics dilute what Google thinks the site is about.

    Recommended, Aldo's call: move the six-rung cluster to blueprintau.com/blog/ with a 301 per URL, so it sits next to the $2,000 offer it sells, and keep aldo.ltd focused on Aldo and Claude Code costs. If it stays, add a "Writing" block on the homepage that links the pillar post.

  8. P1ClaudeBot and Meta's crawler get blocked, against robots.txt

    The server answers 418 to ClaudeBot and meta-externalagent on aldo.ltd and blueprintau.com, while robots.txt says Allow: / and the GEO post tells readers to let AI crawlers in. Claude-SearchBot and Claude-User get through, so Claude's search still reaches the site; the block hits the training crawlers.

    Pick one policy. Either turn off the AI-bot block in the hosting panel or firewall, or keep it and add matching Disallow groups in robots.txt so what the site says matches what it does.

  9. P2Sitemap dates are stale

    Every lastmod says 23 Sep. The server says home changed 6 Oct and /audit/ 29 Sep. Google ignores lastmod once it learns the dates are unreliable.

    Use drop-in/sitemap.xml, built from each URL's real Last-Modified, which adds the engagement letter PDF. Update lastmod only when content changes.

  10. P2Duplicate /index.html and a bare 404

    /index.html answers 200 (the canonical tag covers it). Unknown URLs get the server's default 404, with no nav and no way back.

    Add the rules in htaccess-additions.txt and a /404.html with the site header and links to Home, Audit and Blog.

  11. P2Diary entries are thin

    The two diary posts have 223 and 358 words, no breadcrumb and a standalone author block. That's fine for a diary, but they won't rank.

    Give them the shared @graph (Person and Breadcrumb). Spend writing time on the pages below instead. Skip FAQPage schema: since 2023 Google shows FAQ rich results only for government and health sites.
